2. Important Concepts:

  - C Compiler (GCC) - Converting C source code into executable code.
  - Preprocessor - Processing directives such as #include and #define.
  - Compilation - Converting C code into assembly language.
  - Assembly - Generating object files.
  - Linking - Combining object files and libraries.
  - main() - Entry point of a hosted C program.
  - Header Files - Providing function and type declarations.
  - printf() - Displaying formatted output.
  - scanf() - Reading user input.
  - Variables - Storing data in memory.
  - Constants - Representing values that should not be modified.
  - stdint.h - Fixed-width integer types for Embedded C.
